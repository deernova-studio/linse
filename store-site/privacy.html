隐私政策

更新日期：2026 年 10 月 20 日
适用于临色 0.3.0 及之后采用本政策的版本。

临色由 ruixing shi 开发。本政策说明应用如何处理照片、本地配置与可选 AI 请求。

本地编辑

导入、调色、计算匹配、蒙版识别和导出在设备上完成。临色不要求注册账号，不包含广告或第三方行为追踪。开发者没有接收或集中保存用户照片的应用服务器。

照片在当前编辑会话中用于预览与处理，导出文件保存在你选择的位置。仅使用本地功能时，临色不会将照片发送给 AI 服务。

可选 AI 服务

当你配置 AI 服务并选择“AI 辅助匹配”时，应用先显示接收照片的服务地址。只有你同意本次发送，应用才会向该服务发送原图和目标图的缩小预览、色彩统计以及分析指令。预览不含原文件名、GPS 位置或相机元数据；原始照片文件不会上传。

API Key 用于向你配置的服务验证身份。服务可以将请求与你在该服务的账号关联，并看到请求内容、网络连接信息等数据。其处理目的、保存期限、删除渠道及其他条款以该服务的隐私政策为准。临色无法保证所有自定义服务采用相同的处理规则。

“获取模型”和“测试连接”会访问所配置的服务并使用 API Key，但不发送你的照片。AI 服务可能单独收费。

选择、保存与删除

每次发送照片前均可取消。你可以不配置 AI，继续使用本地调色、匹配与导出。已发出的请求无法撤回；如需删除服务端记录，请联系接收请求的服务提供方。

预设、LUT、外观和 AI 设置保存在设备上。Mac 版 API Key 与本地 JSON 配置一起保存，商店版位于应用沙盒中；iPhone 和 iPad 版 API Key 保存在系统钥匙串。临色不会主动把这些数据同步到开发者服务器。系统备份和诊断由设备设置控制。

你可以在应用中删除预设和 LUT、清除已保存的 API Key；导出的照片由你在文件系统中管理。编辑不会自动改写原始文件；导出时由你选择保存位置，并确认是否替换已有文件。需要删除本地应用配置时，可联系开发者获取操作帮助。

支持联系

你主动发送的反馈内容仅用于回复和处理问题，由所使用的邮件服务传递和保存。请避免发送密码、API Key 或敏感照片。如需查询或删除反馈邮件中的个人资料，可通过同一邮箱联系开发者。
