# Independent color references

`Electron/` contains a synthetic 64×48 source and 11 reference renders: identity, all eight built-in presets, individual channel curves, and all HSL bands. RGBA bytes are sRGB encoded with opaque alpha and rows in top-to-bottom order. No user photos are included.

The references were generated by the original Electron/WebGL pipeline, not by the Swift/Metal renderer. `manifest.json` records the independent checkout commit, Electron version, source SHA-256 hashes, and exact parameters. The reference files remain frozen and are never regenerated by the smoke workflow.

The TypeScript/Electron app was retired on 2026-10-16. These files are retained as a frozen migration baseline, not an active app dependency. The old Node/Electron regeneration script has been removed; the normal build and smoke workflow requires only the native project.

The unit-test comparison runner was retired on 2026-11-08. Preserve the original manifest and reference bytes for historical comparison; never regenerate the expected images from the current renderer. The smoke runner uses only the synthetic source as input to real import / match / export flows; it does not claim historical pixel-parity coverage. See `docs/smoke.md` for current acceptance scope.
