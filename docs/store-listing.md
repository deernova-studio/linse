## 简体中文

名称：临色

副标题：从参考照片开始调色

宣传文本：

导入照片与参考图，在 Mac 上匹配色彩、精细调整并导出。无需注册账号，即可使用本地调色工具。

描述：

临色是一款原生照片调色应用。选择一张想调整的照片，再加入一张参考图，把喜欢的色彩方向带入自己的照片。

• 参考图匹配：在设备上计算色彩匹配，并自由调整匹配强度。
• 精细调色：调整曝光、对比度、色温、HSL 与曲线，比较编辑前后的效果。
• 局部调整：结合蒙版处理照片中的不同区域。
• 预设与 LUT：保存常用调色方案，导入 LUT 继续创作。
• 图片与 RAW：导入普通图片及系统支持的相机 RAW，保留原尺寸导出。
• 可选 AI 辅助：连接你自己的 AI 服务，获得参考图分析与调色建议。每次发送照片前会显示接收服务并征求同意。

本地编辑、计算匹配和导出不需要 AI 服务或 API Key。AI 功能需要自行配置支持图片分析的服务，服务提供方可能单独收费。

支持 Apple 芯片 Mac，要求 macOS 14 或更新版本。RAW 兼容性取决于系统支持的相机型号及压缩格式。

关键词：调色,照片编辑,色彩匹配,参考图,RAW,LUT,摄影,曲线,蒙版

## 审核说明

无需应用登录。核心功能可离线使用。

1. 点击左侧“原图”选择照片，点击“目标图”选择另一张参考照片。
2. 点击“计算匹配”，查看预览；右侧可调整颜色参数和匹配强度。
3. 点击“导出”，选择格式及保存位置。
4. 点击已导入的缩略图，可查看图片详情或切换图片。

AI 辅助为可选功能。AI 设置中可选择服务协议并填写服务地址、模型和 API Key。“获取模型”和“测试连接”不发送照片。点击“AI 辅助匹配”后会显示本次请求的服务地址，明确同意后才发送两张缩小预览；取消不会发送。预览不包含原文件名、GPS 或相机元数据。使用未修改的模型支持列表，不能据此保证所有第三方服务都兼容。

审核联系人姓名、邮箱及经负责人确认的电话已于 2026 年 10 月 22 日保存至 Apple 后台；电话不记录在仓库。已取消“需要登录”，支持与隐私政策 URL 也已保存。

AI 是使用用户自备 API Key 的可选客户端功能。审核备注说明本地测试路径与 AI 发送授权流程，审核凭证通过 App Store Connect 提供。
