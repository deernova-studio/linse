# 图片预览与中性工具栏

## 行为

- 按用户反馈替换 0.2.3 的强调色匹配按钮：顶部动作统一使用中性文字和图标，悬停与按下时才显示浅色背景。缺图、处理中仍明确禁用；导出保留原生菜单与展开箭头。
- 空图片槽点击导入，已有图片点击进入预览。macOS / 宽屏左侧完整显示图片，右侧显示名称、像素尺寸及文件中实际存在的格式、大小、色彩空间、位深、拍摄设备与时间；窄屏上下排列。
- “切换图片”在预览内选择新图，成功后刷新当前预览；取消或读取失败保留原图。移动端使用预览内部的照片选择器。
- 预览在独立 actor 中生成，最长边不超过 2560 像素，不放大小图；保留原图供编辑与导出，切换图片时取消旧预览任务。

## 验证

- `swift test`：47 项，46 通过，1 项可选外部 AI 测试跳过，0 失败。新增元数据、方向、超大图片预览限制及换图保留状态测试。
- macOS 编译及 iOS 共享代码编译通过；本次未运行移动端设备界面。
- 独立 macOS 测试应用已实测深浅外观、原图和目标图预览、竖图完整显示、详情滚动、更换后同步更新，以及取消选择不改变原图。
