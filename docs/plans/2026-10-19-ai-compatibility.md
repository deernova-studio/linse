# AI 接口兼容修复

## 问题与边界

用户在 OpenAI 兼容中转服务、GPT-5.5、很高思考强度下收到 HTTP 502，且快速模式被禁用。502 的具体上游原因无法仅从截图确认，不将客户端修复等同于服务恢复。保持用户现有接口地址、模型和密钥；不调用付费服务、不上传用户照片。

调查过程中用户确认 502 来自其 API 服务，并已自行修复。模型列表请求与实际模型推理是独立链路，列表成功不代表推理可用；此次客户端修复针对快速模式、参数兼容和诊断提示，不归因于或声称修复该服务故障。

## 修复方案

- OpenAI 快速模式使用 `service_tier: priority`；保留 Anthropic 的现有请求方式。两种协议均可保存快速模式，界面说明服务支持及费用条件，不承诺实际加速。
- OpenAI 使用 `max_completion_tokens`。仅在接口明确拒绝该参数时尝试一次旧字段 `max_tokens`，不因 502 重试或私自切换模型、思考强度、服务地址。
- 将网关错误、权限、额度问题说明清楚，并保留状态码、服务域名和错误详情。测试连接不把空回复、截断回复或其他接口的 JSON 误报为成功。
- 完整显示测试结果；设置变化后清除过期结果，旧请求不能覆盖新的设置状态。

只改必要的 AI 请求、设置界面和保存逻辑。保留已有未提交的界面修改，不更改最低系统版本。
