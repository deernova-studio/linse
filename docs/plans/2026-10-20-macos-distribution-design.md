# macOS 直接分发

- 使用已有 Developer ID Application 证书，正式签名和 Apple 公证完成后再提供对外分发的 DMG。
- 保留 macOS 14 最低版本；根据用户要求，仅支持 Apple 芯片（M 系列），所有 Mac 打包入口固定编译 arm64。打包和公证前检查产物仅包含 arm64，安装包文件名明确标记该架构。
- `package.sh --release` 生成独立的发布候选目录，启用强化运行时和安全时间戳。保留本机开发构建入口，不覆盖正在运行的应用。
- `notarize.sh` 使用钥匙串中的公证配置，不在脚本、仓库或命令参数中保存密码。先公证应用并附上票据，再制作和公证 DMG，确保安装后的应用也附带票据。
- 应用通过签名验证、票据验证和 Gatekeeper 检查后才生成 `build/releases` 下的正式 DMG 与 SHA-256 校验文件。保存提交 ID 和日志，便于中断后继续。
- 验证：脚本语法、现有 Swift 测试、arm64 Release 构建、签名和运行检查。公证授权由账户持有人完成；没有授权时只提供已签名的候选应用，不声称已经完成公证。
