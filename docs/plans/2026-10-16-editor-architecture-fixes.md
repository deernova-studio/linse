# Editor Architecture Corrections Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Fix all six findings from the architecture review, review and correct the result, verify both platforms, and commit the completed work.

**Architecture:** Keep LinseCore/LinseUI and the existing export actor. Introduce complete value snapshots for edit history, a matching service with a renderer local to each request, and a throwing preset store with transactional UI updates. Protect preset/LUT dependencies, reject unsupported full-resolution export explicitly, and check in genuine Electron rendering fixtures with enforced tolerances.

**Tech Stack:** Swift, SwiftUI, Metal, Core Image, XCTest, Electron/WebGL fixture generation.

## Decisions and alternatives

- Undo captures parameters, the matching baseline, strength, and summary together. A parameter-only patch would leave other transitions inconsistent; a complete app/document framework is unnecessary.
- Matching owns one renderer per request, including across the network suspension. Restoring the shared preview renderer in a catch block would still leave it shared during the request. Local ownership trades a small initialization cost for a simpler lifetime.
- Preset storage throws on failure; save/delete publish a new list only after atomic persistence. A failed load must not silently allow replacement of an unreadable preset file.
- Refuse deletion of LUTs used by saved presets, and reject applying presets with missing LUTs. Other LUT deletions invalidate related history references so undo cannot restore a nonexistent asset. Embedding all LUT data in each preset would duplicate storage and change the existing file format unnecessarily.
- Full-size export rejects dimensions above the GPU limit with a clear error before touching the destination. Preview/proxy callers request downscaling explicitly. A fully streamed renderer needs separate handling of mipmaps and spatial filters; it is not required to make the current export contract honest.
- Version genuine Electron outputs for synthetic images in the Swift test resources. Normal tests need neither a separate checkout nor a running browser. Regeneration is explicit and records its renderer provenance; fixtures are never generated by the implementation under test.
- User authorized implementation, review, corrections, and Git submission. Continue in the existing clean checkout and finish the full scope without an additional approval handoff.

### Review corrections

- Mark historical matching summaries stale when either image changes, so undo/redo cannot revive an obsolete match as current; covered by the matching transition test.
- Check cancellation again after the matching service returns and before publishing a result. Request IDs also guard delayed progress callbacks.
- Reject thumbnails for presets whose LUT is unavailable, avoiding a preview that silently omits the filter.
- Verify failed LUT deletion preserves the usable in-memory LUT, and that repaired preset storage can be reloaded and saved successfully.
