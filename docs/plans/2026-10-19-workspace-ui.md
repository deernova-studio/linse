# 工作区布局与工具栏修复

## 用户要求

- 左侧图片槽的标题、尺寸不能被裁掉。
- 顶部可点击的按钮应有明确的可用样式。
- 没有导入原图时不显示调色面板。

## 原因与实现

图片原先作为 `ZStack` 的布局子视图，`scaledToFill` 按宽高比要求的宽度撑开了固定侧栏。现在两张图片等宽分配，缩略图放在固定高度背景的 overlay 中，只填充已经分配的空间；尺寸以无分组数字显示，空间不足时分两行。

macOS 工具栏原先使用系统默认的灰色样式，主操作还设置了 `.tint(.primary)`。可用按钮在实际界面中与禁用按钮很相似。现在主匹配操作使用强调色填充，其他按钮保留高对比度文字；缺图或忙碌时才降为禁用样式，并通过悬停说明缺少的条件。图标按钮也补齐了可访问名称。导出仍使用原生菜单。

macOS / iPad 的右侧面板，以及 iPhone 的底部编辑区，仅在 `state.source != nil` 时出现。只导入目标风格图时仍保留导入引导；导入原图后可以立即手动调色，无须等两张图齐全。
