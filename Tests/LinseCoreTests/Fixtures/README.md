# Independent color references

`Electron/` contains a synthetic 64×48 source and 11 reference renders: identity, all eight built-in presets, individual channel curves, and all HSL bands. RGBA bytes are sRGB encoded with opaque alpha and rows in top-to-bottom order. No user photos are included.

The references were generated by the original Electron/WebGL pipeline, not by the Swift/Metal renderer. `manifest.json` records the independent checkout commit, Electron version, source SHA-256 hashes, and exact parameters. The normal Swift suite reads these checked-in files and never regenerates them.

The TypeScript/Electron app was retired on 2026-10-16. These files are retained as a frozen migration baseline, not an active app dependency. The old Node/Electron regeneration script has been removed; the normal build and test workflow requires only the native project.

Run the comparisons with:

```sh
swift test --filter ParityTests
```

Preserve the original manifest and reference bytes. Any intentional algorithm change must explain its effect on this baseline; do not replace independent expected output with output from the Swift renderer under test merely to make a comparison pass. All three input paths (RGBA8, Core Image, and CGImage) must have mean RGB byte error ≤ 0.5 and maximum error ≤ 4. Those limits allow GPU quantization differences but reject visible aggregate shifts and isolated large errors; an intentional color-shift test verifies the gate.

Tiled export is independently compared against a whole-frame render with spatial effects enabled, including the final partial tile. RGBA8 maximum error is one byte level. The 16-bit comparison bounds normalized error to 1/1024 (less than one quarter of an 8-bit level), allowing floating-point coordinate interpolation between different viewports.
